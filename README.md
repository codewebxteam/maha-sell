# Maha Sell

India's premier e-commerce shopping destination featuring mega deals, unbeatable savings, and curated lifestyle collections. Built with Next.js, Tailwind CSS, and Framer Motion.

## Features
- **Multi-Department Catalog**: Men's Wear, Women's Fashion, Kids' Wear, Footwear, Mega Deals, and more.
- **Dynamic Category & Product Management**: Integrated with Firebase Firestore & ImageKit media upload.
- **Interactive Shopping**: Faceted filters, real-time search, responsive product catalog, and sorting.
- **Cart & Wishlist**: Real-time state management with cart slide-over, coupon application, and persistent storage.
- **Checkout & Payments**: Razorpay payment gateway integration, COD support, and order confirmation.
- **Admin Management Panel**: Manage products, inventory, categories, promotional banners, and orders.
- **Modern Responsive UI**: Mobile-first luxury e-commerce experience with smooth micro-interactions.

## Getting Started
